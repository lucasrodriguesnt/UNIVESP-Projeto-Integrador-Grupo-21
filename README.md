## UNIVESP-Projeto-Integrador-Grupo-21
# Compara aí - Comparador de produtos em atacado
Projeto estudantil desenvolvido para a entrega do Projeto Integrador solicitado pela UNIVESP

## Descrição do projeto
Comparador de preços em atacado para pequenos comerciantes de periferias 

## Objetivo
Ajudar comerciantes locais a encontrar os melhores preços possíveis na reposição de estoque, possibilitando a manutenção de preços competitivos e um possível aumento no lucro, auxiliando assim a continuidade desse tipo de pequena empresa.
